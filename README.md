# 📊 Excel Sales Dashboard

An interactive **Excel Dashboard** built using **Power Query, Power Pivot, DAX, Pivot Charts, Charts, Slicers, and Filters** to transform raw business data into meaningful insights and support data-driven decision-making.

---

## 📌 Project Overview

This project demonstrates how Microsoft Excel can be used as an end-to-end data analytics and visualization tool.

The workflow starts with importing and cleaning raw data using **Power Query**, creating a structured **data model using Power Pivot**, developing **DAX measures**, and finally building an interactive dashboard using **Pivot Charts, Charts, Slicers, and Filters**.

---

## 🎯 Project Objectives

The main objectives of this project are:

- Clean and transform raw data using **Power Query**
- Build a structured relational **data model**
- Create calculated measures using **DAX**
- Analyze sales and business performance
- Create interactive visualizations
- Enable users to filter and explore data dynamically
- Identify important business trends and performance indicators
- Present complex data in an easy-to-understand dashboard

---

## ❓ Business Questions

The dashboard is designed to answer questions such as:

1. What is the overall sales performance?
2. What is the total revenue generated?
3. How many products/orders were sold?
4. Which products generate the highest sales?
5. Which categories perform the best?
6. Which regions/locations contribute the most to sales?
7. How does sales performance change over time?
8. Which customers contribute the most revenue?
9. What are the major trends and patterns in the business?
10. Which areas may require further business attention?
